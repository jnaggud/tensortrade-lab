# Research modules

The [paper-inspired research extensions](paper151/README.md) contain experimental accounting engines, strategy adaptations, ensemble studies, and Pine examples. These complement the packaged application in `src/tensortrade_lab`.

Source is public; historical archives and operational outputs remain local. Start with the synthetic demo and unit tests before supplying your own historical data. Read the [research overview](../docs/RESEARCH_RESULTS.md) for the scope of the published findings.
